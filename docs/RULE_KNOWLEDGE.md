# 检测规则与知识边界

## 知识来源

本项目不把通用安全名词当作实践知识。当前结论来自仓库中可执行的规则、固定样例和 13 项回归测试。扫描器输出是确定性初筛证据，不是完整 SAST 结论。

## 可执行判定条件

| 规则 | 当前触发条件 | 不应直接下结论的情况 |
|---|---|---|
| `CMD_INJECTION` | `exec`、`execSync`、`system`、`popen` 或 `shell_exec` 接收请求参数等外部输入；支持先赋值再调用的简单跨行模式 | 固定命令加独立参数数组、严格白名单或输入根本不可控 |
| `SQL_INJECTION` | `query`、`execute` 或 `raw` 中出现字符串拼接/模板插值，并引用请求参数或已标记变量 | 占位符与参数分离的预编译查询；表名等标识符仍需另外白名单复核 |
| `PATH_TRAVERSAL` | 文件读写 API 直接接收请求参数、`filename` 或 `path` | 路径已解析到固定根目录且已校验解析结果未越界 |
| `HARDCODED_SECRET` | 变量名包含 `apiKey`、`secret`、`token` 或 `password`，且字符串常量长度不少于 8 | 测试占位符、公开标识符或文档示例可能误报；不规则命名的真实密钥可能漏报 |
| `WEAK_HASH` | 出现 `md5(...)` 或 `sha1(...)` 调用 | 非安全用途的校验和兼容场景需人工判断；密码存储不应因改成 SHA-256 就视为安全 |

## 证据与阈值

- 单次请求最多 `200000` 个字符，超限直接拒绝。
- 证据保留命中行及真实行号，单条证据最多 `180` 个字符。
- 风险等级是项目规则的预置等级，不是 CVSS 计算结果。
- 模型只能解释工具返回的 `ruleId`、行号和证据；其他观察必须放入“待人工复核”。

## 失败和误判经验

- 纯正则无法识别别名、包装函数、跨函数或跨文件污点传播，因此存在漏报。
- 变量名或 API 形状类似即触发的规则可能在已做白名单、边界校验或非安全用途时误报。
- 修复建议是复核起点，不能替代框架语义、业务权限与可利用性验证。
- 回归测试同时包含应命中和不应命中的样例，防止仅为“有输出”优化。
